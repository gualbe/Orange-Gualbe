# Orange-Gualbe 3.41.0+gualbe.2

**Orange-Gualbe** es una distribución de
[Orange](https://github.com/biolab/orange3) centrada en la velocidad y la
robustez con datos grandes. Sigue a la versión oficial y le añade mejoras de
rendimiento y correcciones.

- **Base:** la versión oficial **Orange 3.41.0**, del 8 de noviembre de 2026.
  Incluye todas sus novedades, entre ellas la traducción al castellano.
- **Verificación:** 6105 tests sin fallos en macOS (Apple M4 Max, Python
  3.12, scikit-learn 1.9.1), con numpy 2.3 y pandas 2.3 y también con numpy
  2.5 y pandas 3.1.
- **Resultados:** idénticos a los de Orange oficial, salvo los cambios
  intencionados que se indican en las
  [notas de 3.41.0+gualbe.1](https://github.com/gualbe/Orange-Gualbe/releases/tag/3.41.0%2Bgualbe.1).

## Descargas

| Sistema | Fichero | Cómo instalar |
|---|---|---|
| **Windows** (64 bits) | `Orange-Gualbe-3.41.0+gualbe.2-Python312-win_amd64.exe` | Ejecuta el instalador |
| **Mac con Apple Silicon** (M1–M4) | `Orange-Gualbe-3.41.0+gualbe.2-Python3.12.10-arm64.dmg` | Abre el `.dmg` y arrastra Orange-Gualbe a Aplicaciones |
| **Mac con Intel** | `Orange-Gualbe-3.41.0+gualbe.2-Python3.12.10-x86_64.dmg` | Igual que el anterior |
| **Linux** (x86_64 y ARM) y cualquier sistema con `pip` | wheels `orange3-3.41.0+gualbe.2-*.whl` (Python 3.11–3.14) | Ver abajo |

- Orange-Gualbe se instala **junto a Orange oficial, sin sustituirlo**: tiene su
  propio nombre, carpeta y entrada en el registro de Windows.
- Los instaladores incluyen numpy 2.3, scipy 1.18 y scikit-learn 1.9, las
  versiones con las que se ha validado. En Mac con Apple Silicon, numpy y
  scipy usan **Accelerate**, la librería de álgebra lineal de Apple.
- Cada instalador se ha probado ejecutando la suite completa de tests sobre la
  app instalada.
- **Los instaladores no están firmados digitalmente.** Windows mostrará el aviso
  de SmartScreen («editor desconocido»): pulsa *Más información → Ejecutar de
  todas formas*. En macOS, la primera vez abre la app con clic derecho →
  *Abrir* (o *Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente*).

**Instalación con pip** (Linux, o Windows y Mac sin instalador), con Python
3.11–3.14:

```bash
python3 -m venv orange-gualbe
source orange-gualbe/bin/activate        # en Windows: orange-gualbe\Scripts\activate
pip install --find-links "https://github.com/gualbe/Orange-Gualbe/releases/expanded_assets/3.41.0%2Bgualbe.2" \
    "orange3==3.41.0+gualbe.2" PyQt6 PyQt6-WebEngine
python -m Orange.canvas
```

`pip` elige el fichero adecuado a tu sistema y versión de Python.

## Novedades respecto a 3.41.0+gualbe.1

**De Orange 3.41.0 oficial:**

- Traducción al castellano y compatibilidad con Python 3.15, numpy 2.4 y
  pandas 3.
- kNN con distancia del coseno; Silhouette Plot muestra la silueta media;
  opciones de vista (título y ejes) en Distributions.
- Scatter Plot permite recolocar puntos a mano y agrupar regiones densas.
- CSV Import resuelve rutas relativas a la carpeta del workflow.
- Los ficheros recientes de File, Load Model y Distance File ya no se guardan
  dentro del workflow.
- Unas 40 correcciones más (Select Rows, Concatenate, Rank, Distributions,
  Tree Viewer, Jaccard, Box Plot, Wayland…).
  [Notas oficiales](https://github.com/biolab/orange3/releases/tag/3.41.0).

**De Orange-Gualbe:**

- La conversión desde pandas (Python Script, add-ons, CSV Import) ya no
  intenta leer como fechas las columnas categóricas de texto. Con 3.41.0
  oficial, una columna categórica cuyas categorías parecían fechas se
  convertía en variable de tiempo, y la conversión de 1M filas tardaba un
  45 % más.
- CSV Import con pandas 3 vuelve a leer columnas de fechas con zonas
  horarias mezcladas.
- Elastic Net con validación cruzada funciona con scikit-learn 1.5 y 1.6.
- Tres correcciones que Orange-Gualbe traía antes que Orange oficial ya son
  oficiales: Nomogram con regresión logística multiclase, el cierre de
  Datasets durante una descarga y Excel con cabecera de tres líneas sin
  indicadores.

Las mejoras de rendimiento y el resto de correcciones de 3.41.0+gualbe.1 se
mantienen; por ejemplo, Correlations 5,3× más rápido, escritura `.tab`/`.csv`
3,5×, Merge Data 3,2×, PCA 2,6× y Test & Score 1,5× con 1M filas. Tabla
completa en las
[notas de 3.41.0+gualbe.1](https://github.com/gualbe/Orange-Gualbe/releases/tag/3.41.0%2Bgualbe.1).

## Compatibilidad

- scikit-learn: `>=1.5.1,<1.11`. Orange oficial pone `<1.10`; Orange-Gualbe
  ya cubre los cambios de la 1.10 en regresión logística y MDS.
- numpy y pandas sin tope, como en Orange oficial: validado con numpy 2.5.5 y
  pandas 3.1.1.

## Compilar desde el código (macOS / conda)

```bash
git clone https://github.com/gualbe/Orange-Gualbe.git
cd Orange-Gualbe
git checkout 3.41.0+gualbe.2
conda create -n orange-gualbe -c conda-forge python=3.12 numpy scipy \
    "scikit-learn<1.11" pandas bottleneck cython "pyqt=5.15" pyqtwebengine \
    anyqt matplotlib pyqtgraph qtconsole openpyxl xlrd xlsxwriter networkx \
    opentsne python-louvain "xgboost<2.1" "libblas=*=*accelerate"
conda activate orange-gualbe
pip install -e . --no-build-isolation
python -m Orange.canvas
```
