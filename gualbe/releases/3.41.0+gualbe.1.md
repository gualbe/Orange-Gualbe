# Orange-Gualbe 3.41.0+gualbe.1

Primera versión de **Orange-Gualbe**, una distribución de
[Orange](https://github.com/biolab/orange3) centrada en la velocidad y la
robustez con datos grandes. Sigue a la versión oficial y añade mejoras de
rendimiento y correcciones.

- **Base:** upstream master `71c3613e0` (desarrollo de 3.41.0, posterior a la
  versión oficial 3.40.0).
- **Verificación:** 6098 tests sin fallos en macOS (Apple M4 Max, Python 3.12,
  scikit-learn 1.9.1, numpy 2.3.5). Cada cambio tiene sus tests y mediciones de
  antes y después.
- **Resultados:** idénticos a los de Orange oficial salvo en los casos indicados
  abajo como cambios intencionados.

## Más rápido

1M filas × 50 atributos; tiempo desde que el widget recibe los datos hasta que
su salida está lista.

| Operación | Orange oficial | Orange-Gualbe | Mejora |
|---|---:|---:|---:|
| Correlations | 10,5 s | 2,0 s | 5,3× |
| Escritura `.tab`/`.csv` (datos con 3 decimales) | 24,4 s | 6,9 s | 3,5× |
| Merge Data | 3,5 s | 1,1 s | 3,2× |
| Contingencias (Box Plot, Distributions, Naive Bayes…) | 9,4 s | 3,0 s | 3,1× |
| PCA | 8,5 s | 3,3 s | 2,6× |
| Impute / Continuize | 0,54 / 0,43 s | 0,24 / 0,19 s | 2,3× |
| Rank | 6,6 s | 3,0 s | 2,2× |
| Feature Statistics | 4,6 s | 2,5 s | 1,9× |
| Lectura `.tab`/`.csv` (datos con 3 decimales) | 18,9 s | 10,3 s | 1,8× |
| Preprocess / Predictions | 2,3 / 2,2 s | 1,3 / 1,4 s | 1,7× |
| Test & Score (Naive Bayes, regresión logística y árbol; CV 5) | 87,2 s | 59,5 s | 1,5× |

Además, el árbol de clasificación de Orange es 1,8× más rápido, los ficheros
UTF-8 con tildes o eñes ya no se leen dos veces, y la escritura de ficheros
usa memoria acotada (~45 MB) en vez de proporcional al tamaño.

## Correcciones

Resultados erróneos sin aviso:

- kNN con distancia de Mahalanobis reutilizaba la covarianza del primer ajuste
  ([#7311](https://github.com/biolab/orange3/issues/7311)) y fallaba al
  predecir con scikit-learn 1.9.
- `add_column` con datos dispersos dejaba la columna en `NaN`
  ([#6748](https://github.com/biolab/orange3/issues/6748)).
- Un apóstrofo en un `.tab`/`.csv` podía hacer perder filas al leer
  ([#6067](https://github.com/biolab/orange3/issues/6067)).
- Al guardar, los números perdían cifras: -22112215 se escribía como
  -2.21122e+07 ([#6916](https://github.com/biolab/orange3/issues/6916)).
- Los identificadores de más de 15–16 cifras perdían dígitos al leerlos
  ([#6203](https://github.com/biolab/orange3/issues/6203)).
- Nomogram mostraba probabilidades erróneas con regresión logística
  multiclase ([#7326](https://github.com/biolab/orange3/issues/7326)).
- Select Columns podía adoptar la selección de otro Select Columns
  ([#7020](https://github.com/biolab/orange3/issues/7020)).
- DBSCAN sustituía el `eps` elegido al reabrir el workflow
  ([#6047](https://github.com/biolab/orange3/issues/6047)).
- CSV Import leía fechas de una misma columna con formatos distintos
  ([#6499](https://github.com/biolab/orange3/issues/6499)).
- La "Silhouette" de k-Means no era la silueta
  ([#7280](https://github.com/biolab/orange3/issues/7280)): se añade la
  columna "Silhouette score" con la silueta real.

Errores y cierres:

- Datasets cerraba Orange al cambiar de dataset durante una descarga
  ([#7343](https://github.com/biolab/orange3/issues/7343)).
- Fallos en Group By con fechas discretizadas
  ([#7065](https://github.com/biolab/orange3/issues/7065)), Merge Data con PCA
  ([#7132](https://github.com/biolab/orange3/issues/7132)), Excel sin clase
  ([#7276](https://github.com/biolab/orange3/issues/7276)), Predictions al
  cambiar de clase ([#6672](https://github.com/biolab/orange3/issues/6672)),
  Venn Diagram con datos dispersos
  ([#5700](https://github.com/biolab/orange3/issues/5700)) y contingencias con
  datos dispersos y pesos.

## Compatibilidad

- Preparado para scikit-learn 1.10 y 1.11 en regresión logística, MDS y
  Gradient Boosting, con resultados idénticos.
- Limitado a `scikit-learn<1.11` hasta migrar las probabilidades del SVM.

## Cambios intencionados en los resultados

- Los números se guardan con todas sus cifras. Con datos de precisión completa
  los ficheros son más grandes y lentos de escribir y leer que con las 6
  cifras de antes; con datos de pocas cifras no cambia nada.
- Las fechas ambiguas de CSV Import se leen con un único formato por columna.
- Los enteros de más de 2^53 sin tipo declarado se leen como texto.

## Instalación (macOS / conda)

```bash
git clone https://github.com/gualbe/Orange-Gualbe.git
cd Orange-Gualbe
git checkout 3.41.0+gualbe.1
conda create -n orange-gualbe -c conda-forge python=3.12 "numpy<2.4" scipy \
    "scikit-learn<1.11" "pandas<3" bottleneck cython "pyqt=5.15" pyqtwebengine \
    anyqt matplotlib pyqtgraph qtconsole openpyxl xlrd xlsxwriter networkx \
    opentsne python-louvain "xgboost<2.1"
conda activate orange-gualbe
pip install -e . --no-build-isolation
python -m Orange.canvas
```
